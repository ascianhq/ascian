Your first request

How do I run something, in the workspace, the terminal, or from code?

Pick whichever fits. All three draw from the same balance and the same catalog.

In the workspace

Sign in, open https://ascian.fun/chat, choose a model in the picker and type. The price of the turn is shown before you send and the cost is shown when it finishes. The workspace.

In the terminal

The CLI needs Node 18 or newer and nothing else. It remembers your key and your model.

ascian login asks for a key from your wallet and saves it. ascian on its own opens a conversation. Quote a question to ask once and exit: ascian "what changed in HTTP/3?". The CLI.

From your own code

Make a key at https://ascian.fun/wallet#api. The base URL is https://ascian.fun/v1 and the shape is the OpenAI chat completions API.

The response is the OpenAI shape plus one field of ours, ascian.credits_charged, so your code knows what the call cost without a second request.

Switch models by changing one string

Every chat model in the catalog works with the same request. Ids are exact, so copy them from the catalog rather than guessing: claude-sonnet-5, gemini-3.7-flash, deepseek/deepseek-v4.1-flash.
