Show the working.

The same four rules run through every page on this site, from a single model guide to the credit calculator.

  1. 01

    Start from the finished output

    Every guide begins with the deliverable, not the model. A clip, a page, a voiceover or an answer sets the unit that the rest of the analysis has to respect.

  2. 02

    Price the provider's native unit

    Tokens, images, seconds and characters stay in the unit the provider bills. We never flatten unlike outputs into one misleading headline price.

  3. 03

    Count the attempts, not the wins

    Usable output includes the retries. A rate that looks cheap per run can be the expensive route once the accepted-output count is honest.

  4. 04

    Recheck when the catalog moves

    Catalog rates and model line-ups change. Each guide carries the review date, and the numbers are indicative until you confirm the quote for a run.
